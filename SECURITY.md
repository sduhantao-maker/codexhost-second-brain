# Security

**English** · [简体中文](#安全问题)

Please report security problems privately, through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for them.

Say what is affected, how to reproduce it and what it lets someone do. Leave out real conversation text, tokens and other personal data; a made-up example is enough.

What counts, for example: conversation text or secrets reaching a model, the log or another surface unmasked; files written outside the extension's data folder other than the agent integration's own hook and section; a crafted conversation, PR title or saved passage running code or commands.

Fixes go into the next release. Only the latest release is supported.

# 安全问题

[English](#security) · **简体中文**

发现安全问题时，请通过 GitHub 的私密漏洞报告提交：打开仓库的「Security」页签，选择「Report a vulnerability」。请不要为此开公开的 issue。

写清受影响的部分、复现步骤，以及别人能借此做到什么。不要附上真实的对话内容、令牌或其他个人数据，编一个例子就够了。

比如：对话内容或密钥未经遮挡就到了模型、日志或其他界面；在插件数据目录之外写了文件（Agent 协作自己的 hook 和那一段说明除外）；精心构造的对话、PR 标题或收藏内容能执行代码或命令。

修复会放进下一个版本。只支持最新发布的版本。
